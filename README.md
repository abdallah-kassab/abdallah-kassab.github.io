# Abdallah Al-Hawary — Official Portfolio

نسخة أولية مجانية وجاهزة للنشر لموقع:
Abdallah Al-Hawary / عبدالله الهواري / عبدالله كساب

## الملفات
- `index.html` الصفحة الرئيسية.
- `style.css` التصميم.
- `README.md` تعليمات النشر.

## النشر المجاني
يمكن نشر هذه الملفات على خدمة استضافة صفحات ثابتة مثل GitHub Pages أو Cloudflare Pages.

## قبل النشر النهائي
1. استبدال `https://example.com/#person` داخل JSON-LD بالرابط الفعلي للموقع.
2. إضافة صورة رسمية وfavicon.
3. إضافة روابط YouTube/Instagram/Facebook/TikTok المؤكدة.
4. إضافة صفحة مستقلة لكل عمل مهم مع السنة، الدور، البوستر، الفيديو والمصادر.
5. إضافة sitemap.xml وrobots.txt.
6. ربط الموقع بـ Google Search Console بعد نشره.
7. مراجعة أي ادعاء عن الجوائز أو الجهات أو نسب المشاهدة وإرفاق مصدر منشور أو صورة موثقة عند الإمكان.

ملاحظة: هذا الموقع لا ينشئ Knowledge Panel تلقائيًا؛ الهدف هو بناء حضور رقمي متسق وموثوق يساعد محركات البحث على فهم الهوية والأعمال.
